# YawaMetrics — нативная док-панель OBS Studio

![version](https://img.shields.io/badge/version-2.1.1-8b5cf6) ![platform](https://img.shields.io/badge/platform-Windows%20x64-121222) ![obs](https://img.shields.io/badge/OBS%20Studio-30%2B-22c55e) ![license](https://img.shields.io/badge/license-GPL--2.0--or--later-f43f5e)

**YawaMetrics** показывает в OBS Studio суммарное количество зрителей
мультистрима в реальном времени — без API-ключей: достаточно ссылки на канал.

Поддерживаются **6 площадок**: VK Video Live, Twitch, YouTube, TikTok LIVE,
Kick и GoodGame.

---

## Возможности

- **Док-панель OBS** — «Вид → Док-панели → YawaMetrics»; пристыковывается к
  любой стороне окна или плавает, раскладку запоминает сам OBS.
- **Счётчики без ключей** — каждая площадка опрашивается по ссылке на канал.
  Опциональные API-ключи (Twitch Client ID/Secret, YouTube Data API v3,
  VK-токен) используются, только если вы их ввели.
- **Два режима**: Полный (карточки площадок, названия стримов, сводка) и
  Компактный (плитки «площадка + число») — переключение одной кнопкой,
  выбор сохраняется между запусками.
- **«Всего зрителей»** — сумма только по включённым площадкам в эфире,
  обновление ≤ 1 с после опроса.
- **Не мешает стриму** — все запросы асинхронные, UI-поток OBS не блокируется.
- **Виджет для сцены** — `widget.html` для Browser Source: 6 стилей
  (Панель, Стопка, Бейдж, Карточки, Минимал, Бегущая строка), 5 цветовых
  акцентов, прозрачность, скругления, масштаб, размытие. Настройки кодируются
  в URL — ссылка копируется одной кнопкой.
- **Тёмная тема** и локализация (ru-RU / en-US).

## Установка

### Вариант 1: ZIP-архив (ручная установка)

1. Скачайте `yawametrics-<версия>-windows-x64.zip` со страницы
   [Releases](https://github.com/yawaside/YawaMetricks.OBS.plugin/releases).
2. Закройте OBS Studio и распакуйте архив в каталог OBS Studio
   (обычно `C:\Program Files\obs-studio`).
3. Запустите OBS Studio, откройте «Вид → Док-панели → YawaMetrics».

### Вариант 2: установщик .exe

Запустите `yawametrics-<версия>-windows-x64-setup.exe` — он сам найдёт OBS
Studio (реестр, Program Files, `%LOCALAPPDATA%\Programs\obs-studio`).
Удаление — штатно, через «Установка и удаление программ».

> Требования: Windows 10/11 x64, OBS Studio 30.0 или новее.

## Первые шаги

1. Нажмите **«⚙ Настройки»** в шапке панели → вкладка **«Площадки»**.
2. Выберите площадку, включите её и вставьте **ссылку на канал**
   (подойдёт и просто ник).
3. Нажмите **«Проверить подключение»** — плагин покажет статус и число
   зрителей.
4. Готово: счётчики обновляются автоматически (интервал 10–120 с).

Статусы: **LIVE** (зелёный, пульсирует) · **ОФЛАЙН** (серый) ·
**ОШИБКА** (красный, пояснение в tooltip) · **ВЫКЛ** · **НЕ НАСТРОЕНО** ·
**…** (загрузка).

## Виджет для сцены

«⚙ Настройки» → вкладка **«Виджет»**: выберите стиль, акцент, прозрачность,
скругление, масштаб, размытие и состав элементов — и нажмите
**«Скопировать ссылку»**.

В OBS: «Источники → + → Браузер», снимите флажок «Локальный файл» и вставьте
ссылку. Ссылка самодостаточна и воспроизводит все настройки. Положение
оверлея задаётся обычной трансформацией источника OBS.

Из браузера виджет напрямую опрашивает Twitch и Kick (они отдают
CORS-заголовки); счётчики остальных площадок всегда доступны в док-панели.

## Сборка из исходников

Требования: Windows x64, Visual Studio 2022 (MSVC), CMake ≥ 3.28, Ninja.

```powershell
# 1. Скачать зависимости (Qt6, obs-deps, заголовки и portable OBS 29.1.3,
#    сгенерировать obsconfig.h и import-библиотеки):
./scripts/Install-ObsDeps.ps1

# 2. Сконфигурировать и собрать (версию передавать в кавычках):
cmake --preset windows-ci-x64 "-DYAWAMETRICS_VERSION=2.1.1"
cmake --build --preset windows-ci-x64
```

Результат: `native/.build/windows-ci-x64/yawametrics.dll` + дистрибутивная
раскладка в `native/.build/windows-ci-x64/package/`.

Сборка комплекта ZIP: `.github/scripts/package-zip.ps1 -Version <версия>`.

## CI и релизы

| Джоба            | Назначение                          | Блокирующая |
|------------------|-------------------------------------|-------------|
| `lint-cmake`     | синтаксис CMake (`check_cmake.py`)  | да          |
| `lint-version`   | согласованность версии (`check-version.mjs`, 7 файлов) | да |
| `web`            | проверка `widget.html` и его размера | да        |
| `native`         | компиляция `yawametrics.dll`        | да          |

При пуше в `main` автоматически создаётся тег `vX.Y.Z` и GitHub Release с
ZIP-комплектом ручной установки. Версия берётся из первой записи `## X.Y.Z`
в `CHANGELOG.md` — единственного источника версии. Сборка установщика `.exe`
выполняется с `continue-on-error`: её сбой не отменяет публикацию релиза.

```

  src/             plugin-main, config, poll_engine, ui/*

scripts/           Install-ObsDeps.ps1 — конвейер зависимостей
installer/         Inno Setup + тексты дистрибутива
.github/           CI-воркфлоу и предполётные проверки
docs/              TECHNICAL_SPEC.md — техническое задание
```
