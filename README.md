# YawaChatHub 3.0.0

**Единая лента чата со всех стримов + озвучка голосом + виджет для OBS + игровой оверлей.**
Моно-репозиторий: сайт-витрина, интерфейс приложения и Electron-оболочка собраны из одного кода —
окно программы рендерит тот же интерфейс, что показан на сайте.

Площадки: **Twitch · YouTube Live · VK Play Live · Kick · TikTok Live**.

| Часть                 | Путь                          | Описание                                                |
| --------------------- | ----------------------------- | ------------------------------------------------------- |
| Сайт + живое демо     | `src/`, `index.html`          | витрина; демо = настоящее окно приложения               |
| Интерфейс приложения  | `src/components/DesktopApp.tsx` | лента, каналы, озвучка, настройки (шестерёнка в шапке) |
| Оверлей               | `src/components/OverlayApp.tsx` | компактная лента поверх игры                            |
| Electron-оболочка     | `desktop/electron/`           | окна, трей, хоткеи, SAPI TTS, коннекторы, сервер виджета |
| OBS-виджет            | `desktop/widget/`             | прозрачная страница для Browser Source                   |
| CI                    | `.github/workflows/release.yml` | автосборка → автотег → авторелиз                       |

Релизная линия начинается с **3.0.0**. GitHub Actions автоматически выпускает
следующую patch-версию: `3.0.0` → `3.0.1` → `3.0.2`.

## Что нового в 3.0.0

* Эффекты появления сообщений с настройкой скорости и живым предпросмотром.
* Сворачиваемая панель каналов: полный список или компактный мини-бар с иконками.
* Восстановлена озвучка сообщений системными голосами Windows.
* В шапке оставлено только название приложения; сведения о версии и сборке перенесены
  в «О программе».
* «Сворачивать в трей при закрытии» по умолчанию выключено.

## Интерфейс приложения

* **Главная** — каналы со статусами, единая лента (поиск, фильтр площадок, автопрокрутка)
  и панель управления озвучкой.
* **Настройки** — шестерёнка в шапке (пока открыты, на её месте крестик): озвучка, фильтры,
  вид ленты, OBS-виджет, оверлей, горячие клавиши, тема интерфейса, о программе.
* Все площадки подключаются строго по **username канала** — ссылки отклоняются.
* Заголовок окна — свернуть / во весь экран / закрыть (окно без системной рамки).

## Режимы интерфейса

* **Сайт** — без Electron работает демо-симуляция чата.
* **Приложение** — `#/app`: полноценное окно со всеми разделами.
* **Оверлей** — `#/overlay`: прозрачная лента поверх игры.

## Загрузка через Git Bash: автосборка, автотег, авторелиз

1. Создайте **пустой** репозиторий на github.com (без README).
2. Откройте Git Bash в корне проекта:

```bash
git init
git add .
git commit -m "feat: YawaChatHub 3.0.0"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```

Важно: файлы `.exe` не нужно добавлять командой `git add -f`. Папка
`desktop/release/` специально указана в `.gitignore`: GitHub ограничивает один
файл обычного репозитория размером 100 MB. Portable и установщик загружаются
как assets релиза, а не в историю исходников.

### Если `git push` не проходит

Запустите из корня проекта универсальный скрипт:

```bash
bash scripts/push-github.sh main "feat: update YawaChatHub"
```

Скрипт сам выставляет правильный `origin`, убирает случайно добавленные
сборки из индекса, создаёт коммит и выполняет `push`. Если установлен GitHub CLI,
перед этим выполните:

```bash
gh auth login
gh auth setup-git
```

Если Git Bash сообщает, что локальная и удалённая истории не связаны, скрипт
остановится и покажет команды. Не используйте `--force`, пока не проверите,
что на GitHub нет нужных коммитов.

3. Один раз включите права для Actions:
   **Settings → Actions → General → Workflow permissions → Read and write permissions → Save.**
4. Что произойдёт автоматически после `git push`:

   * workflow `build · tag · release` соберёт интерфейс и оба exe (Windows x64);
   * создаст первый тег **v3.0.0**, а при следующем push — `v3.0.1`, `v3.0.2` и далее;
   * сформирует ченжлог (`scripts/changelog.sh`), обновит `CHANGELOG.md` в репозитории;
   * опубликует Release с файлами `YawaChatHub.exe` и `YawaChatHub-Setup.exe`.

   Промежуточные сборки доступны в **Actions → Artifacts**, а готовые файлы —
   во вкладке **Releases**.

Если Git Bash показывает `nothing to commit` после сборки exe — это нормально:
в коммит попадают исходники, а оба Windows-файла публикует GitHub Actions.

5. Следующий функциональный релиз создаётся обычным push:

```bash
git add .
git commit -m "feat: краткое описание новой функции"
git push
```

   Дальше конвейер сам увеличит patch-версию: сборка → тег → релиз.
   В публичный changelog попадают только коммиты `feat:`, `fix:`, `ui:` и `perf:`.

Тэг можно создать и вручную — но это не обязательно:

```bash
git tag -a v3.0.0 -m "YawaChatHub 3.0.0"
git push --tags
```

## Быстрый старт (разработка)

```bash
npm install
npm run dev                 # сайт с живым демо
```

Ручная сборка приложения:

```bash
npm run build
xcopy dist desktop\renderer-dist /E /I /Y
node scripts/sync-version.mjs 3.0.0
cd desktop
npm install
npm run dist:all            # portable + установщик → desktop/release
```

В Git Bash на Windows можно собрать обе версии одной командой:

```bash
bash scripts/build-windows.sh 3.1.2
```

После этого файлы находятся в `desktop/release/`. Для ручной публикации
локальных файлов в GitHub Release (если не хотите ждать Actions) установите
[GitHub CLI](https://cli.github.com/), выполните `gh auth login`, затем:

```bash
bash scripts/upload-release.sh 3.1.2
```

Скрипт создаёт или обновляет Release `v3.1.2` и загружает оба файла.

Документация приложения: [desktop/README.md](desktop/README.md) — подключение каналов, фильтры,
OBS-виджет, оверлей, горячие клавиши. Сборка: [desktop/BUILD.md](desktop/BUILD.md).
