# Silero TTS — анализ для YawaChatHub

## Что это

Silero Models (https://github.com/snakers4/silero-models) — открытые предобученные модели TTS.
Нас интересует только **русский язык**, строго `ru`.

Модели:
- `v5_ru` — актуальная, ~60 МБ, поддерживает авто-ударения (`+` для ударения), 48000/24000/8000 Гц
- `v4_ru` — ~50 МБ, 6 голосов: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`, `random`

Пример использования (Python):
```python
import torch
model, _ = torch.hub.load('snakers4/silero-models', model='silero_tts', language='ru', speaker='v5_ru')
audio = model.apply_tts(text="Привет из чата!", speaker='kseniya', sample_rate=48000)
```

## Можно ли встроить в YawaChatHub

**Да, можно**, но с оговорками:

### Вариант A — через Python (реализован в этом репозитории как опция)
- В `desktop/electron/silero_tts.py` — постоянный процесс Python, который слушает JSON из stdin
- В `desktop/electron/silero.js` — Node-обёртка, которая поднимает Python и управляет очередью
- В `main.js` — выбор движка: SAPI или Silero, в зависимости от `settings.tts.backend`

**Плюсы:**
- Лучшее качество русского голоса, чем SAPI
- Офлайн после первой загрузки модели
- Поддерживает эмоции/скорость через параметры

**Минусы / нагрузка:**
- Требует установленного Python 3.10+ и `pip install torch torchaudio silero soundfile`
- RAM: +350-500 МБ к приложению (torch + модель)
- CPU: 1 ядро 40-70% во время синтеза, RTF ~0.3 (5 сек аудио синтезируется за ~1.5 сек)
- GPU: если есть CUDA — в 3-5 раз быстрее, нагрузка минимальна
- Диск: torch ~200 МБ + модель ~60 МБ
- Первый запуск: 3-5 сек на загрузку модели + скачивание ~60 МБ
- Portable exe вырастет с ~180 МБ до ~500+ МБ, если бандлить torch (поэтому сейчас Silero — опционально)

### Вариант B — через ONNX Runtime (для будущей оптимизации)
- Конвертировать `v5_ru.pt` в ONNX
- Использовать `onnxruntime-node` в Electron без Python
- RAM: ~150-200 МБ, CPU ниже, нет зависимости от Python
- Требует дополнительной работы по конвертации и токенизации

### Вариант C — через облако (не рекомендуется)
- Отправлять текст на внешний API — нарушает требование офлайна и приватности

## Текущая реализация в 3.1.4

- Добавлен переключатель движка в `Настройки → Озвучка`: `Windows SAPI` / `Silero RU`
- Добавлен выбор голоса Silero: aidar, baya, kseniya (по умолчанию), xenia, eugene, random
- Если Python/torch не установлены — автоматически используется SAPI, без ошибок
- Для OBS-виджета: если выбран Silero, аудио синтезируется в WAV (base64) и отправляется в Browser Source, где воспроизводится через `<audio>` — тогда OBS захватывает звук при включённой опции «Управлять аудио через OBS»
- Для SAPI через OBS тоже добавлен WAV-путь (раньше использовался только speechSynthesis, который OBS часто не захватывал)

## Установка Silero (для пользователей, кому нужно)

1. Установите Python 3.10+ https://python.org и добавьте в PATH
2. В командной строке:
   ```
   pip install torch torchaudio silero soundfile --extra-index-url https://download.pytorch.org/whl/cpu
   ```
3. Запустите YawaChatHub, в настройках озвучки выберите `Silero RU` и голос
4. При первом запуске модель скачается автоматически (~60 МБ) в кеш torch

Если не хотите ставить — просто оставьте `Windows SAPI`, всё будет работать как раньше.

## Рекомендация

- По умолчанию оставляем SAPI (лёгкий, без зависимостей, работает везде)
- Silero — опциональный премиум-голос для тех, кто готов поставить Python и пожертвовать ~400 МБ RAM
- В релиз `Releases` Silero не бандлится, чтобы не раздувать exe. Пользователь ставит сам, если нужно.
