## Нативный плагин OBS Studio «YawaMetrics»

| | |
|---|---|
| **Изделие** | `yawametrics.dll` — док-панель OBS Studio на C++/Qt |
| **Версия ТЗ** | 1.0 |

| **Лицензия** | GPL-2.0-or-later |

## 1. Общие сведения

### 1.1. Назначение изделия

Нативная док-панель OBS Studio, отображающая в реальном времени количество
зрителей одновременной трансляции на нескольких площадках, а также браузерный
оверлей (виджет) для вывода счётчика на видео сцены.

### 1.2. Цели

| № | Цель | Критерий достижения |
|---|------|---------------------|
| Ц-1 | Видеть суммарный онлайн всех площадок в одном окне | Единое поле «Всего зрителей», обновление ≤ 1 с после опроса |
| Ц-2 | Работать без обязательных API-ключей | Все 6 площадок дают счётчик только по ссылке на канал |
| Ц-3 | Не мешать стриму | UI-поток OBS не блокируется ни на одном этапе |
| Ц-4 | Вписываться в интерфейс OBS | Тёмная тема, штатный док, раскладку помнит OBS |
| Ц-5 | Устанавливаться без ручной настройки | ZIP-распаковка в каталог OBS или .exe-установщик с автопоиском OBS |

### 1.3. Область применения

Windows 10/11 x64, OBS Studio 30.0 и новее. Мультистримы (одновременная
трансляция на 2 и более площадки).

## 2. Термины

| Термин | Определение |
|--------|-------------|
| Док | Панель, встроенная в окно OBS через `obs_frontend_add_dock` |
| Площадка | Одна из поддерживаемых стриминговых платформ |
| Полный режим | Режим с карточками площадок, названием стрима, сводкой |
| Компактный режим | Режим с плитками «площадка + число» и суммой |
| Автоподгонка | Уменьшение кегля шрифта до порога читаемости вместо обрезки текста |
| Виджет | HTML-оверлей, подключаемый в OBS как Browser Source |

### 3.3. Источники данных

Приоритет: работа без API-ключей. Ключи — опциональный «официальный» путь.

| Площадка | Endpoint без ключей | Признак эфира | Счётчик |
|----------|--------------------|----------------|---------|
| VK Video Live | `https://live.vkvideo.ru/<ник>` | `"status":"live"` / `"is_live":true` | `viewers \| viewers_count \| online_count` |
| Twitch | `POST https://gql.twitch.tv/gql` (публичный Client-ID веб-плеера) | объект stream не пуст | `data.user.stream.viewersCount` |
| YouTube | `https://www.youtube.com/@<handle>/live` | `"isLive":true` / «N watching now» | `viewCount.simpleText \| shortViewCountText` |
| TikTok LIVE | `https://www.tiktok.com/@<логин>/live` | наличие roomId | `"viewerCount":<int>` |
| Kick | `https://kick.com/api/v2/channels/<slug>` | livestream — объект или is_live | `viewer_count` |
| GoodGame | `https://goodgame.ru/channel/<ник>` | `"status":"live"` | `viewers \| viewer_count \| count` |

| ИД | Требование |
|----|------------|
| ФТ-3.1 | Запросы выполняются через QNetworkAccessManager асинхронно, не блокируя UI-поток |
| ФТ-3.2 | Таймаут одного запроса — 10 с |
| ФТ-3.3 | Устанавливается User-Agent браузера (часть площадок блокирует пустой UA) |
| ФТ-3.4 | Ответ разбирается регулярными выражениями в raw-строках с пользовательским разделителем (запрещено `R"(...)"` с кавычками внутри — см. §12.1) |
| ФТ-3.5 | Сетевая ошибка → статус «ОШИБКА» с пояснением в tooltip |
| ФТ-3.6 | Ответ получен, но эфира нет → статус «ОФЛАЙН» |
| ФТ-3.7 | Кнопка «Проверить подключение» прогоняет тот же путь, что обычный опрос, и выводит результат текстом |
| ФТ-3.8 | Опциональные ключи (Twitch Client ID/Secret, YouTube Data API v3, VK-токен) используются только если пользователь их ввёл |

### 4.3. Ключевые типы

```cpp
namespace yawametrics {
enum class PlatformId { Vk, Twitch, YouTube, TikTok, Kick, GoodGame };
constexpr int kPlatformCount = 6;
extern const PlatformId kPlatformOrder[kPlatformCount];

struct PlatformSettings {
    bool    enabled = false;
    QString channel;   // ник / handle / ссылка
    QString key;       // опциональный API-ключ
    QString secret;    // опциональный секрет
};

struct AppConfig {
    int    pollIntervalSec  = 15;
    bool   showStreamTitle  = true;
    bool   autoStartPolling = true;
    bool   compactMode      = false;
    int    uiScalePercent   = 100;
    bool   compactHideNames = false;
    double compactScale     = 1.0;
    PlatformSettings platforms[kPlatformCount];
    PlatformSettings&       platform(PlatformId);
    const PlatformSettings& platform(PlatformId) const;
    QJsonObject toJson() const;
    static AppConfig fromJson(const QJsonObject&);
    static AppConfig load();
    void save() const;
};

// Состояние площадки, готовое к отрисовке. Объявлено на уровне
// пространства имён, а НЕ внутри PollEngine.
struct PlatformUiState {
    PlatformId id         = PlatformId::Vk;
    bool configured = false;   // канал заполнен
    bool enabled    = false;   // опрос включён
    bool live       = false;
    bool loading    = false;
    long long viewers = 0;
    QString title, statusText, detail, source;
};

class PollEngine : public QObject {
    Q_OBJECT
public:
    explicit PollEngine(AppConfig, QObject* parent = nullptr);
    void applyConfig(const AppConfig&);
    AppConfig config() const;
    void setPolling(bool);
    bool isPolling() const;
    int  secondsLeft() const;
    void pollNow();
    void testPlatform(PlatformId);
    PlatformUiState state(PlatformId) const;
signals:
    void snapshotReady(PlatformId, PlatformUiState);
    void tick(int secondsLeft, int intervalSec);
    void pollingChanged(bool);
    void testFinished(PlatformId, bool ok, QString message);
};
} // namespace yawametrics
```

## 5. Технические требования

### 5.1. Стек

### 5.2. Зависимости и версии

| Зависимость | Версия | Назначение |
|-------------|--------|------------|
| libobs (заголовки) | 29.1.3 | obs-module.h |
| obs-frontend-api (DLL для линковки) | 29.1.3 | obs_frontend_add_dock |
| obs-deps | 2026-08-26 | libcurl и сторонние библиотеки |
| Qt6 prebuilt | 2026-08-26 из obs-deps | — |
| OBS Studio (у пользователя) | 30.0+ | среда выполнения |

Критично: версии заголовков и DLL для линковки обязаны совпадать.
Расхождение приводит к `LNK2019: unresolved external symbol`.
29.1.3 — последняя версия OBS с Windows portable ZIP.

### 5.3. Векторные иконки

Иконки площадок задаются SVG path-данными в `platformIconPath()` и рисуются
через `QPainterPath`.

Требуется парсер команд `M/m L/l H/h V/v C/c Q/q Z/z` с поддержкой
относительных координат. Команда `A/a` (дуга) упрощается до хорды.

| NeonDot | Фиксированный размер 12×12, пульсация только в live |
| PulseDot | Радиус 3.0 ± 1.2 px по синусоиде, период ~1400 мс |
| PollProgressBar | Высота 4 px, скругление 2 px, заполнение = доля до цикла |
| SwitchBox | Трек 46×24 px, скругление 12 px; ручка 18 px; «выкл» `#2b3240`, «вкл» `#22c55e`; подсветка при наведении |

### 6.4. Размеры дока

| Режим | Минимум | База | Максимум ширины |
|-------|---------|------|-----------------|
| Полный | 320 × 430 px | 380 × 560 px | 480 px |
| Компактный | 260 × 210 px | 300 × 230 px | 360 px |

Все значения умножаются на масштаб (§ ФТ-5.4, ФТ-5.5).

### 8.1. Пайплайн зависимостей

scripts/Install-ObsDeps.ps1

## 9. Дистрибутив и установка

### 9.1. Комплект ручной установки (обязателен, всегда публикуется)

`yawametrics-<версия>-windows-x64.zip`:

```
obs-plugins/
  64bit/
    yawametrics.dll
data/
  obs-plugins/
    yawametrics/
      yawametrics.qss
      widget.html
      locale/
        ru-RU.ini
        en-US.ini

```

Установка: распаковать в каталог OBS Studio, перезапустить OBS.

### 9.2. Установщик .exe (дополнительно, best-effort)

Inno Setup. Автопоиск OBS: реестр (`HKLM`/`HKCU`, включая `WOW6432Node`) →
`Program Files\obs-studio` → `%LOCALAPPDATA%\Programs\obs-studio`.

Требование к CI: сбой сборки `.exe` не должен отменять релиз. Шаг выполняется
с `continue-on-error: true`; ZIP-комплект публикуется в любом случае.

### 9.3. Удаление

Через «Установка и удаление программ»: удаляются `yawametrics.dll` и
`data/obs-plugins/yawametrics` из каталога OBS.

## 11. Ограничения реализации (обязательные к соблюдению)

| ИД | Ограничение | Причина |
|----|-------------|---------|
| ОР-1 | Raw-строки с кавычками внутри писать только как `R"YM(...)YM"` | `R"("...")"` закрывается на первой кавычке → C2017 / C2760 |
| ОР-2 | Полный тип нужен до вызова метода: `#include <QResizeEvent>`, `<QStyle>`, `<QShowEvent>` | C2027: use of undefined type |
| ОР-3 | class / struct в forward-declaration и определении обязаны совпадать | C4099 → ошибка при `/WX` |
| ОР-4 | Лямбда — не указатель: `auto f = [&]{}`, не `auto *f = [&]{}` | C3535 |
| ОР-5 | Не использовать локальные имена, совпадающие со std (например narrow) | C2737 |
| ОР-6 | В CMake запрещено `${VAR[0]}` — только `list(GET VAR 0 out)` | синтаксическая ошибка CMake |
| ОР-7 | Опции iscc передавать до имени скрипта | иначе «more than one script filename» |
| ОР-8 | В PowerShell флаг `-D...=1.2.3` брать в кавычки | иначе парсер разбивает токен |
| ОР-9 | Типы общего назначения (`PlatformUiState`) объявлять в пространстве имён, а не внутри класса | иначе C2039 |
| ОР-10 | Функции `obs_frontend_add_dock_by_id` / `obs_frontend_remove_dock(id)` доступны только с OBS 30+ | при линковке с 29.x — LNK2019 |
| ОР-11 | Все консольные скрипты для Windows — только на английском или с явным UTF-8 | UnicodeEncodeError на cp1252 |

## 12. Критерии приёмки

### 12.1. Сборка

- [ ] `cmake --preset windows-ci-x64` завершается без ошибок
- [ ] `cmake --build --preset windows-ci-x64` создаёт `yawametrics.dll`
- [ ] Сборка без предупреждений при `/W3`
- [ ] `check_cmake.py` и `check-version.mjs` проходят

### 12.2. Установка

- [ ] ZIP распакован в каталог OBS → пункт «Вид → Док-панели → YawaMetrics» присутствует
- [ ] `.exe`-установщик находит OBS, установленный в Program Files и в `%LOCALAPPDATA%`
- [ ] Удаление через «Установка и удаление программ» не оставляет файлов в каталоге OBS

### 12.3. Функциональность

- [ ] Каждая из 6 площадок отдаёт счётчик по одной ссылке на канал, без ключей
- [ ] Площадка не в эфире → «ОФЛАЙН»; сеть недоступна → «ОШИБКА» с пояснением
- [ ] «Проверить подключение» выводит результат и число зрителей
- [ ] «Всего зрителей» = сумма только живых включённых площадок
- [ ] Переключение Полный ⇄ Компакт меняет размер окна плавно и сохраняется
- [ ] Масштаб 140 % (полный) и 1.30 (компакт) — ничего не обрезано
- [ ] Число 1 234 567 отображается целиком, без многоточия, на любом масштабе
- [ ] Название стрима длиной > 60 символов обрезается с многоточием, полный текст в tooltip
- [ ] Настройки переживают перезапуск OBS
- [ ] При выключенном интернете плагин не падает

### 12.4. Виджет

- [ ] `widget.html` открывается как Browser Source с прозрачным фоном
- [ ] Все 6 стилей и 5 акцентов применяются
- [ ] Прозрачность 0 % даёт полностью прозрачный фон
- [ ] Ссылка с параметрами воспроизводит настройки без UI

### 12.5. Релиз

- [ ] При пуше в `main` создаётся тег `vX.Y.Z`
- [ ] В релизе присутствует ZIP-комплект ручной установки
- [ ] Версия в релизе совпадает с CHANGELOG и со свойствами `yawametrics.dll`
- [ ] Сбой сборки `.exe` не отменяет публикацию релиза
