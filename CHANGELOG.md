# Ченжлог YawaChatHub

## YawaChatHub v3.0.0

### Новые возможности

- Добавлены эффекты появления сообщений: проявление, подъём снизу, сдвиг справа,
  масштабирование, Pop и пружина; скорость эффекта настраивается.
- Панель каналов можно свернуть в компактный мини-бар с иконками площадок и
  индикаторами состояния.
- Виджет OBS получил полную настройку оформления: свой цвет фона, текста, ника,
  времени, рамки и акцентной полоски с быстрым сбросом к цветам темы.
- Для виджета добавлен выбор шрифта, насыщенности, размера ника и внутренних отступов.
- Любой элемент плашки виджета можно отключить: значок площадки, ник, время,
  рамку, акцентную полоску и тень.

### Исправления

- Восстановлена озвучка новых сообщений системными голосами Windows.
- Настройка «Сворачивать в трей при закрытии» по умолчанию выключена.

### Интерфейс

- В шапке главного окна оставлено только название приложения с новой иконкой.
- Версия, тип сборки, режим desktop, количество каналов и число активных эфиров
  перенесены в раздел «О программе».
- Настройки эффектов получили живой предпросмотр с кнопкой повторного запуска.
- Пресеты фильтров стали интерактивными плашками: кнопка «Применить» убрана,
  включение происходит нажатием на карточку.
- Активный пресет выделяется зелёной обводкой, а при наведении размывается
  и показывает «Отмена».
- Предпросмотр виджета OBS обновляется мгновенно и повторяет итоговый вид плашек.

## YawaChatHub v2.0.2

### Исправления

- Улучшена стабильность подключения к площадкам и отображение их статусов.
- YouTube Live подключается без пользовательского API-ключа.
- Добавлена проверка доступности площадок из приложения.

## YawaChatHub v2.0.1

### Исправления

- Исправлена прозрачность игрового оверлея.
- Оверлей можно перемещать и изменять его размер; позиция запоминается.
- События подключения больше не попадают в озвучку.
- Добавлена кнопка скрытия событий подключения из ленты.

## YawaChatHub v2.0.0
