# Ченжлог YawaChatHub

## YawaChatHub v2.0.2

**Сборка:** YawaChatHub.exe (portable x64) и YawaChatHub-Setup.exe (NSIS installer x64)

### Исправления

- **Подключение к площадкам полностью переписано**: предыдущий net.js использовал
  скрытое окно Chromium (`BrowserWindow` + `executeJavaScript`) — молча ломался при
  старте, все каналы падали в «ошибка». Теперь простой `https`-модуль Node.js
  с браузерными заголовками — работает без Chromium.
- **Twitch**: анонимный IRC поверх WebSocket (`justinfan`), без tmi.js — работает
  сразу при старте.
- **Kick**: API-запросы с правильным User-Agent и Referer — Cloudflare пропускает.
- **YouTube**: без API-ключа — через страницу `/live` и внутренний endpoint `youtubei`.
- Добавлено подробное логирование (`[conn:twitch]`, `[conn:kick]` и т.д.) для отладки.

## YawaChatHub v2.0.1

**Сборка:** YawaChatHub.exe (portable x64) и YawaChatHub-Setup.exe (NSIS installer x64)

### Исправления

- Оверлей больше не чёрный квадрат: глобальный фон страницы и зернистая плёнка закрашивали
  прозрачное окно Electron — добавлен режим `overlay-mode` с полностью прозрачным фоном.
- Оверлей можно перетаскивать мышью: добавлена шапка-ручка (`-webkit-app-region: drag`),
  позиция и размер запоминаются в `settings.json` (`overlayBounds`).
- Настройки оверлея применяются мгновенно: конфиг рассылается напрямую в окно оверлея.
- **YouTube работает без API-ключа**: чат читается через внутренний endpoint
  `youtubei/v1/live_chat`, как в браузере. Ключ Google Cloud больше не требуется.
- Озвучка не читает служебные события подключения; на главной появилась кнопка-колокольчик
  для скрытия таких событий из ленты.


## YawaChatHub v2.0.0

**Дата:** 2026-02-15

**Сборка:** YawaChatHub.exe (portable x64) и YawaChatHub-Setup.exe (NSIS installer x64)

### Правки и новые возможности

- Убраны кнопки «Сохранить» во всех разделах настроек: любое изменение применяется и
  сохраняется сразу (settings.json рядом с exe, localStorage — на сайте).
- Починена настройка «Сворачивать в трей при закрытии»: переключатель больше не заглушка,
  реально управляет поведением крестика, дублируется в меню трея.
- Добавлены настройки поведения окна: сворачивание в трей кнопкой «минус», запуск свёрнутым в трей.
- Версия 2.0.0 синхронизирована в интерфейсе, в Git-теге и в пакете приложения.
- Сборка теперь даёт две сборки Windows x64: portable exe и NSIS-установщик с ярлыками.
- Настроен конвейер GitHub Actions: автосборка → автотег → авторелиз с автосгенерированным ченжлогом.
