# Голоса Silero в YawaChatHub

Silero — это открытые нейросетевые голоса высокого качества
([snakers4/silero-models](https://github.com/snakers4/silero-models)).
На русском есть модели `v5_ru` со спикерами: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`.

## Можно ли добавить их в приложение?

Да. Silero — это PyTorch-модели (Python), запустить их напрямую из Electron/Node
не получится. Но у автора Silero есть **готовая SAPI5-обвязка для Windows** — она
регистрирует голос Silero как системный (тот же интерфейс, что использует
Балаболка и все Windows-читалки).

YawaChatHub уже озвучивает чат через Windows SAPI5, поэтому **никакого нового
кода не требуется**: после установки голос Silero сам появится в списке голосов
в разделе «Озвучка → Голос».

## Установка (Windows x64)

1. Скачайте установщик Silero TTS для Windows (SAPI5) — статья автора:
   [Синтез Silero теперь работает локально под Windows как экранная читалка (SAPI5)](https://habr.com/ru/articles/981992/).
2. Запустите установщик. В процессе выберите **только русские голоса**
   (v5_ru: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`) — остальные скачивать не нужно.
3. Перезапустите YawaChatHub. Если голоса не появились сразу — нажмите в приложении
   `Настройки → Озвучка → Голос → Обновить`. Приложение читает голоса из реестра
   `HKLM\SOFTWARE\Microsoft\Speech\Voices` (SAPI) и `Speech_OneCore\Voices` (OneCore).
4. Откройте `Настройки → Озвучка → Голос` — там появятся Silero-голоса вида `Silero - aidar`.

## Нагрузка на компьютер

Silero легковесный по меркам нейросетевых TTS:

- **CPU:** одно короткое сообщение (5–10 слов) синтезируется за ~150–400 мс на
  среднем ноутбуке (i5, без видеокарты). Загрузка ядра на этот момент 50–90 %,
  дальше 0 %.
- **RAM:** после первого синтеза модель остаётся в памяти, занимает
  примерно **300–500 МБ**.
- **GPU:** не требуется. Silero отлично работает на CPU.
- **Диск:** сама модель `v5_ru` весит около 60 МБ, установщик SAPI-обвязки
  добавляет ещё до ~250 МБ (кэш моделей).

По сравнению со стандартным Microsoft SAPI («Ирина», «Максим») Silero звучит
намного естественнее, но чуть тяжелее. На современном ПК разница в загрузке
незаметна, и стрим/игра не проседают.

## Если голоса Silero не появились

- Убедитесь, что установщик Silero отработал без ошибок.
- Проверьте `Настройки → Время и язык → Речь → Управление голосами` — там
  должны быть строки вида `Silero (aidar)`, `Silero (xenia)`.
- Полностью перезапустите YawaChatHub (не только окно, а через трей → «Выход»).
